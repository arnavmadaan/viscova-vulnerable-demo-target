# Security policy

This repository is **deliberately insecure by design**. It is a test fixture for
authorized, sandboxed security testing. The vulnerabilities are intentional.

- **Do not report** the planted vulnerabilities as security issues — they are the
  whole point of the project.
- **Do not deploy** this app, and do not put real data in it.
- If you find a problem that is *not* one of the documented planted bugs (for
  example, something in the tooling around it), open an issue.

All data in this repository is fake.
